# 第 15 次课教师实施指南（P5 v1.0—v1.2）

## 一节课的明确终点

学生发布一个可访问的课堂点歌站：搜索、去重点歌、播放/暂停/下一首、排序、暂停点歌、操作日志和断网回退全部可演示；每条外部音乐都能追溯来源与许可。

## 三学时节奏

| 学时 | 教师演示 | 学生交付 | 验收 |
|---|---|---|---|
| 1 | v1.0：Pinia 队列、状态机、浏览器合成音 | 搜索、入队、播放、下一首 | 重复不入队；空队列不报错；搜索“断网”出现重试提示 |
| 2 | v1.1：Adapter 契约、许可字段、失败回退 | Mock/合法来源可切换 | 许可页可达；不抓取、不缓存；外部失败不清空队列 |
| 3 | v1.2：主持台、排序、锁定、日志、限流 | 完整课堂 URL 与 Release | 同一名字一分钟第 3 次请求被拒；刷新后队列恢复 |

## 课前检查

1. 执行 `npm ci && npm run check && npm test && npm run build`。
2. 打开生产 URL，先用“课堂合成音”完成主流程，外部音源只做补充演示。
3. 核对 `docs/music-sources.md` 中三个许可页。许可状态变化时立即停用条目。
4. 准备网络关闭演示：现有队列和本地合成音仍可操作。

## 演示与追问

1. 搜索“音乐”，由“小满”连续点歌，观察重复拦截和频率限制。
2. 播放一首后排序，确认当前歌曲身份不随索引错位。
3. 进入主持台，暂停点歌、切歌、移除、查看日志。
4. 切到合法公开来源，打开许可页；说明“能访问”不等于“可任意传播”。
5. 搜索“断网”，确认 UI 失败态、重试入口和既有队列仍存在。

## 验收清单

- [ ] 正常：搜索、点歌、播放、暂停、下一首、排序。
- [ ] 边界：空关键词、重复歌曲、空队列、刷新恢复。
- [ ] 失败：模拟断网、外部音频错误、点歌限流。
- [ ] 代码：Adapter、Pinia、状态机、来源文档与锁文件齐全。
- [ ] 证据：绿色 CI、Release/Tag、Netlify URL 和测试记录。
